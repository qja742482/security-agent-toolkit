## pwd 가 출력한 경로를 적어 두고, 윈도우 탐색기 주소창의 경로와 표기가 어떻게 다른가
깃배쉬는 /c/Users/user, 윈도우는 C:\Users\user로 구분 기호(/와 \)와 드라이브 표기가 다르다.


## 이걸 왜 배우는지

보안 담당자는 왜 리눅스 명령어를 쓸까요?
보안 담당자가 지키는 대상(서버)이 대부분 리눅수라서,그 안을 직접 즐여다보려면 리눅스 명령어를 알아야 하기 때문이다

개발자와 보안 담당자는 왜 깃허브에 코드를 올릴까요?
코드를 안전하게 보관하고,변경 기록을 남기고,여러 사람이 함께 작업하기 위해서이다.

## 이 말들이 무슨 뜻인지

터미널
명령어를 글자로 입력해서 컴퓨터를 다루는 프로그램이다
화면이 없는 서버를 관리할 때 꼭 필요하다.

경로(path)
파일이나 폴더가 컴퓨터 안 어디에 있는지 알려 주는 주소이다.
예: /c/Users/user

깃배쉬 (Git Bash)
윈도우에서 리눅스 명령어를 쓸 수 있게 해 주는 터미널 프로그램
